## Content Rules

- Keep one clear intent per page.
- Keep one H1 per page.
- Use comparison pages for honest positioning, not competitor keyword stuffing.
- Do not claim official integrations or availability that the product does not have.
- Do not add structured data unless it mirrors visible page content.

## Search Cluster Notes

The expanded solution cluster borrows the hub-and-spoke pattern from `AgriciDaniel/codex-seo`:

- `/solutions/` is the pillar page.
- `/brand/noderoom/` handles exact-brand disambiguation for the bare `noderoom` query.
- Each `/solutions/.../` spoke targets one search intent and links back to adjacent pages.
- Public pages explain the product; private app, room, demo, and create URLs stay noindex.
- New pages should be checked in Search Console for impressions before adding more spokes.
