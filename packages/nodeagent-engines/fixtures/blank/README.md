# Blank workspace

This project starts empty. There are no source documents, no check suites and no independent
verifier, so runs here cannot be verified beyond what you inspect yourself.

Use it to try an engine quickly: ask for a small script, a note or a notebook, and watch the run's
tool calls, helpers and artifacts in the workspace view. For a task with real evidence, checks and
independent verification, create a project from the "SMB-lending diligence pack" template instead.
