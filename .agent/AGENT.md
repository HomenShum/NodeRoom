# NodeRoom Agent Harness Rules

- The model reasons; the harness owns tools, budgets, context, ledger writes, and approval gates.
- Convex is the live operational ledger.
- OKF is the portable knowledge bundle.
- Hybrid retrieval is how NodeAgent finds evidence.
- Managed lock/CAS/proposals are how NodeAgent safely changes shared artifacts.
- Never cite sources that were not opened, read, or resolved.
- Never treat room chat or manual notes as verified evidence unless they are labeled as such.
- Never write shared artifacts outside managed CAS/proposal tools.
