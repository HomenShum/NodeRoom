How a NodeRoom moves from prompt to traceable work.

A room starts with people, files, and a goal. NodeAgents can assist, but the important part is the visible loop: context, action, artifact, source, trace, and review.

Start from the landing pageQuestions

1. Create or join

Use a room code to bring people into the same work context.

2. Ask the agent

Give NodeAgent a bounded task against visible room context.

3. Review evidence

Check the artifact, citations, locks, proposals, and trace events before trusting the result.

For public SEO pages, keep examples crawlable. For private rooms, use noindex and scoped room links.
