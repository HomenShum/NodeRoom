BLOCKER RESOLUTION
- Duplicate company labels now receive row-bound entity keys; duplicate dataset,
  frame, child-frame, and cache-key identities fail validation.
- Manual/computed/literal/unverified/tampered evidence remains visible but cannot
  satisfy support or freshness. Only untampered source/upload receipts can.
- Each managed evidence write carries its own verifiedAt and canonical receiptDigest.
- Durable launch receipts bind consent, actor, current plan, exact dataset identity,
  and exact artifact version. The server recomputes and attests those values.
- Job correlation uses only an exact untampered receipt. Artifact/title/goal/session
  heuristics and uncorrelated room-wide telemetry are excluded.
- Output, run, and research-pack digests bind status source, job/run provenance,
  terminal result claims, dataset claim artifacts, and task-run receipts.
- Sparse research scope expands every dataset row across all eight authorized
  research fields and fails closed above 8,192 writes before scheduling.
- Element-scoped execution exposes only `write_locked_cell_result` and
  `write_locked_cell_results`; every durable investigation write declares
  `sealed_cell_payload_v1`, so scalar or forged payloads cannot bypass evidence.
- `resultDigest` is persisted only while terminalizing the exact finalized run,
  binds the authorization and latest mutation receipt, is cleared on retry, and
  is never synthesized by a read query.
