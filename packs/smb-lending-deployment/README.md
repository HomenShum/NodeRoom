# SMB Lending Deployment Pack

This experimental NodeRoom pack turns the independent synthetic Casca FDE exercise
into a reusable room template. It adds lending vocabulary, fixtures, deterministic
graph operations, financial metrics, bounded proposals, work-artifact projections,
and proof receipts. It does not add another agent runtime, state store, proposal
system, trace format, or proof harness.

## Golden slice

1. Load the synthetic restaurant application.
2. Inspect required documents and source-backed financial periods.
3. Explain the missing-bank-statements blocker through the process graph.
4. Create a version-pinned document-request proposal.
5. Require a human review decision before changing room state.
6. Apply the approved proposal through optimistic version checking.
7. Prepare a review packet that explicitly records `decision: not_made`.
8. Project the application, graph, workbook, evidence, packet, and deployment board
   through NodeRoom work-artifact contracts.
9. Emit a content-addressed proof receipt.

The held-out medical-practice fixture changes the missing requirement and financial
shape so the pack cannot pass by hard-coding the restaurant case.

## Authority boundary

Agents may inspect synthetic evidence, calculate deterministic ratios, find graph
blockers, propose document requests, and prepare review packets. A human reviewer
must approve proposals. A credit authority owns every approval, decline, exception,
pricing, and final disposition decision.
